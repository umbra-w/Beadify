# Beadify v1.1.0

本次更新主要增加了裁剪比例预设、重构了 PDF 导出清晰度，并优化了界面显示与网格辅助功能。

### 新功能与改进

- **裁剪比例预设**：新增 1:1（正方形）、1:2、2:1 等快捷比例切换，支持缩放时锁定比例，方便对齐常用拼豆板（如 28×28 或双板拼接）。
- **高清 PDF 导出**：重写 PDF 导出逻辑，色号文字与网格直接按矢量绘制（300 DPI），解决此前导出的 PDF 打印模糊的问题；支持 2.6mm（迷你豆）和 5.0mm（标准豆）真实孔距 1:1 打印。
- **网格参考线**：支持设置每 5 格或每 10 格加粗参考线，并可自定义线条颜色。
- **相似色合并**：新增色彩相似度合并调节，自动归拢相近颜色，减少碎色和杂色用量。
- **界面适配**：支持 Edge-to-Edge 全屏显示，优化状态栏与底部导航栏视觉效果。
- **测试脚本**：补充真机端到端自动化测试脚本（`scripts/run_full_feature_e2e.py`）。
