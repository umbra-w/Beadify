# Beadify v1.2.0

本次更新主要重构了文字拼豆模块，增加了内置开源像素字体、渐变/彩虹选色与描边投影效果，同时扩充了测试覆盖。

### 更新内容

#### 1. 内置开源像素字体
- 内置 3 款常用像素字体，均遵循 SIL OFL 1.1 开源协议（支持商用）：
  - **方舟像素 12px**（Ark Pixel，TakWolf）：经典 12px 中文复古点阵
  - **缝合像素 12px**（Fusion Pixel，TakWolf）：全 CJK 字库覆盖的 12px 像素字体
  - **Press Start 2P**（Google Fonts）：经典 8px 街机风英文字体

#### 2. 颜色模式与物理色板对齐
- **渐变色模式**：支持选取起始色与结束色，底层采用 Oklab 色彩空间进行线性插值，过渡均匀不发灰，并自动寻找物理拼豆色板中最接近的实体色号。
- **彩虹色模式**：自动沿文本列向循环色相环。
- **单色模式**：保持原有的单色快速出图逻辑。

#### 3. 文字描边与投影
- **文字描边**：基于 8 邻域形态学膨胀计算外轮廓，可自定义描边色号。
- **文字投影**：独立坐标层偏移，自动扣除文字笔画重叠区域，可单独开关并选择投影色号。
- 合成优先级统一为：文字笔画 > 描边 > 投影 > 背景。

#### 4. 界面与交互改进
- **全局返回栈规范**：重构并统一页面历史导航栈（`NavigationManager`），彻底解决从“文字拼豆”或“我的项目”进入图纸编辑器后点击返回误跳回启动首页的问题，确保顶栏“返回”按键与系统全局侧滑手势精准返回上一级来源页面。
- 文字拼豆配置页改为平滑滚动视图，兼容各种长宽比屏幕。
- 退出页面后保留已输入的文字内容、字体、字号高度与各项特效配置，重进无需重新选择。

#### 5. 测试与稳定性
- 单元测试新增 NavigationManager 导航栈回退全链路用例，JVM 单元测试总数达到 159 个（全部通过）。
- 真机端到端自动化测试套件（Suite 1 ~ Suite 7）全部回归通过，真机运行 0 崩溃、0 ANR。
