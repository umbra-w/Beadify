# Beadify v1.2.0

本次更新主要升级了文字拼豆功能，增加了开源像素字体、多色渐变与描边投影等效果，并扩充了测试覆盖。

### 新功能与改进

- **内置开源像素字体**：内置方舟像素 12px（TakWolf）、缝合像素 12px（TakWolf）与 Press Start 2P（Google Fonts），均基于 SIL OFL 1.1 授权发布，支持中英文像素字形精准栅格化。
- **色彩模式扩展**：
  - 新增「渐变」模式：在 Oklab 感知色彩空间进行双色平滑插值，并自动对齐所选物理拼豆色板。
  - 新增「彩虹」模式：按列自动循环色相环分布。
- **文字特效图层**：
  - 支持文字描边：基于 8 邻域形态学膨胀算法计算外轮廓，可自定义描边色号。
  - 支持文字投影：独立行列平移图层，自动排除与文字重叠区域，支持自定义阴影颜色。
- **界面优化**：文字拼豆配置面板改为滚动布局，并持久化当前文字、字号与颜色配置，重进页面不丢失。
- **测试与稳定性**：
  - JVM 单元测试新增 29 个测试用例，总数扩充至 150 个（涵盖逆向色值转换、Oklab 插值与形态学膨胀边界）。
  - 真机全链路端到端自动化测试覆盖文字拼豆新特性，全套件 100% 通过。
